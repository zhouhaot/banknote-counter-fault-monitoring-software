# 点钞机运行状态监测与故障管理系统 — Windows 桌面版

C# / WPF / .NET 10 / SQLite。当前处于实施阶段，不能视为完整发布。

本地单机业务台账，支持范围按 docs 中已确认设计推进。状态来自人工或 CSV 记录，软件不连接真实点钞机，不提供实时遥测、预测或自动诊断。

## 开发

需要 .NET 10 SDK；安装器构建另需 Inno Setup 6。

在 desktop 目录执行 `./scripts/verify.ps1` 完成构建、数据测试与依赖审计；执行 `./scripts/publish.ps1` 生成自包含安装包；执行 `./scripts/test-installer.ps1` 验证本机隔离安装、真实窗口流程和卸载保留测试数据。原生 UI 测试需要交互式 Windows 桌面。

当前完成范围与验证限制见 [实施进度](docs/Windows原生版实施进度.md)。

新桌面版使用独立数据库。请勿将旧 Django 数据库直接作为桌面版运行库。
