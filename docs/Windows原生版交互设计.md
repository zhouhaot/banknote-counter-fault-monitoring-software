# Windows 原生版交互设计

2026-09-06，用户已确认交互基线。文字线框不代表已运行窗口。

## 主窗口

默认1280×800 DIP，最小960×640，左侧208 DIP导航可折叠。标题与主操作在顶部，筛选和只读表格居中，下方分页与操作状态。保存窗口位置，显示器变化时回到可见区域。

```text
┌ 点钞机运行状态监测与故障管理系统 ─────────────────┐
│ 概览           │ 设备台账                 [新增设备] │
│ 设备管理       │ 编号[    ] 型号[全部▼] [查询][重置] │
│ 状态与异常     │ 状态[全部▼] 来源[真实业务▼]        │
│ 故障与维修     │ 编号  型号  最近记录状态  位置      │
│ 耗材库存       │ ……                                 │
│ 统计分析       │ [上一页] 第1页/共…页 [下一页]      │
│ 数据导入       ├────────────────────────────────────┤
│ 备份与恢复     │ 本地数据 · 最近保存成功             │
│ 演示数据/关于  │                                    │
└─────────────────────────────────────────────────────┘
```

默认浅色，系统字体及中文回退；正文14 DIP、标题22 DIP，8 DIP间距，表格行高至少36 DIP、按钮至少32 DIP。错误同时有文字，系统高对比度和键盘焦点必须可见。深色主题不列为首版阻断条件。缩放时筛选换行、导航折叠，表格可横向滚动，按钮不被裁切。

## 页面与动作

| 页面 | 内容与动作 | 特殊反馈 |
|---|---|---|
| 概览 | 设备数量、待处理故障、近期记录和入口 | 显示统计时间；无数据引导建档，不自动灌入演示 |
| 型号管理 | 新增、编辑、查询、引用详情 | 重复字段定位，被引用不可删除 |
| 设备台账/详情 | 编号型号、位置、最近记录；基本资料与历史标签页 | 未记录显示“尚无状态记录”，不显示在线/实时 |
| 状态记录 | 时间、状态、累计读数、备注 | 冲突显示前后记录时间读数，保留输入 |
| 异常 | 新建、关闭、转故障 | 已关闭/转换禁用非法动作并解释 |
| 故障与维修 | 故障详情、开始处理、维修时间线、关闭 | 缺维修或最终结果不能关闭 |
| 耗材库存 | 品类、库存、流水、入库领用退回调整更正 | 领用显示剩余量，历史无编辑删除 |
| 统计 | 寿命、年龄、趋势、日期型号筛选 | 缺参数显示不可计算；图表配同口径数据表 |
| 导入 | 选模板、选文件、预览错误、提交、批次 | 有错误不能提交，文件变化重新校验 |
| 备份恢复 | 选择目录/备份、校验、创建/恢复 | 展示版本时间，覆盖有明确确认 |
| 演示数据 | 创建独立集、查看范围、重置 | 模拟标记持续可见，重置不触及真实数据 |
| 关于 | 名称、版本、构建、目录、帮助 | 不显示登记身份证等私人字段 |

## 关键流程

设备建档：点击新增设备，依次填编号、型号、日期、位置、负责人、备注。缺型号可先新增后回填。保存成功选中新记录并展示详情；重复编号定位字段且保留输入。取消有未保存修改需确认。详情标签页包含状态、异常、故障维修及耗材记录，返回保留筛选位置。

故障处理：异常详情选择转故障，预填设备与现象，补充类型/严重度/时间，成功跳转故障详情并保留异常链接。维修按时间线展示；领用作为独立动作预填设备故障，失败不撤销已保存维修，不能描述为共同原子提交。关闭前要求维修和最终结果、合法时间，完成后历史只读。

备份恢复：选择备份后先显示版本、时间和校验结果，合格才出现恢复按钮。确认明确说明当前数据被替换且先创建回退备份。恢复中禁用业务操作，显示真实阶段，不制造百分比；替换阶段不可强制取消。失败说明当前库状态、关联号与回退动作，损坏备份不能进入覆盖。

## 通用交互

DataGrid 默认只读，编辑通过表单；常用动作有可见按钮，不仅放右键菜单。必填项明确，字段错误和顶部摘要并存，保存失败保留输入；查询失败不呈现为零库存。区分无记录与筛选无结果。

Tab/Shift+Tab按视觉顺序；多行文本框Enter不触发保存；Esc遵守未保存提示。标签关联字段，控件有可访问名称，焦点清晰，弹窗关闭回到触发控件。保存中防重复点击，长任务有真实工作状态和安全取消。窗口关闭等待短事务安全结束。
