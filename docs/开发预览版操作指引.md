# Windows 开发预览版操作指引

本指引对应 0.6.0 的已实现界面。各项实际验证结果以《Windows原生版实施进度》为准；本文件不是正式软件著作权使用说明书或完整验收报告。

## 安装与数据

运行 `MoneyCounterMonitor-0.6.0-win-x64-setup.exe`，按向导安装。安装包包含 .NET 运行环境。应用面向 Windows 11 x64，安装包尚未签名。

默认数据目录为 `%LOCALAPPDATA%\MoneyCounterMonitor\data`。卸载程序保留该目录。请勿将旧 Django 数据库直接复制到此目录；新旧程序的数据库结构不同。

## 从设备建档到维修

1. 在“型号管理”新增制造商、型号及额定点钞寿命。缺少额定寿命可以留空。
2. 在“设备台账”新增资产编号，选择型号，补充启用日期、位置和负责人。
3. 选中设备后打开“状态与异常”。登记时间、状态及累计读数；历史补录必须同时满足前后记录的累计读数约束。
4. 登记异常后，可以填写处理意见关闭，或转为故障。
5. 在“故障与维修”开始处理，登记维修动作和结果。关闭故障前必须已有维修记录，并填写最终结论及有效关闭时间。关闭后的维修历史只读。

所有状态均为业务记录。应用不连接真实点钞机，也不提供实时遥测或自动故障诊断。

## 耗材库存

先新增耗材名称和单位，再选中耗材登记入库。数量最多两位小数。领用必须关联设备，库存不足时拒绝保存并保留输入。

从维修详情打开耗材窗口会预填设备与故障。库存操作独立保存，领用失败不会撤销已保存的维修记录。

流水不可编辑或删除。登记错误时，在“库存流水”选择原记录，填写时间和冲正原因，再执行冲正。冲正会保留原记录并新增反向流水；可能导致负库存的冲正会被拒绝。

## CSV 导入

按型号、设备、状态的先后关系导入，每次处理一个文件。点击“保存模板”取得对应固定表头，填写后选择文件，先“预览与校验”，无错误后再“确认导入整批”。

文件要求：UTF-8（允许 BOM），扩展名 `.csv`，不超过 5 MiB、10000 条数据记录，每个单元格不超过 2000 个字符。列名及顺序必须和模板一致。引号包裹的单元格可以包含逗号与换行。日期使用 `YYYY-MM-DD`；状态记录时间必须带时区，例如 `2026-01-01T08:00:00+08:00`。

错误表显示逻辑行号、字段和原因，可导出错误清单。预览后修改文件需要重新预览；提交时还会重新检查数据库引用、重复项和读数时间线。任一错误导致整批不写入。忙碌时可取消，等待事务回滚完成后再关闭窗口。

## 演示数据

“演示数据”使用整数种子创建独立模拟集，覆盖型号、设备、状态、异常、故障维修和耗材流水。列表中的模拟来源标记必须保留，不能将这些记录解释为真实设备事实。

清除模拟集会要求确认。只处理选定模拟集；发现跨来源或跨模拟集引用时，整个清除操作会被拒绝。相同种子不能同时创建两份；清除后可以重新生成。

## 当前限制

备份恢复及完整发布验收仍按实施计划推进。统计分析按北京时间日期计算，默认不包括模拟数据；缺少读数、额定寿命或启用日期时会明确显示为“不可计算”或“未提供”。正式软著材料将在功能冻结后，从同版本源码和实际窗口生成。应用和本指引不包含申请人的私人身份信息。
